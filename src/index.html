管家名单
批量导入 TXT：每行一个名字，例如：张师傅。已存在的名字会自动跳过。选择管家时可按拼音首字母(A-Z)快速筛选跳选。
房台 / 房间管理
批量导入 TXT 格式：房号,区（每行一个，支持英文/中文逗号或制表符），例如：A01,1区、B02,2区。区可省略（省略则归入「未分区」）。
也可单个手动添加。已存在的房号不会重复导入。
报警设置
到钟前提前提醒距离结束还剩多少分钟时卡片变红并弹窗报警（0 = 只在到点时提醒）
全局提示音触发报警时播放提示音；每个房间也可在卡片右上角单独静音
报警提示音时长每次触发报警时提示音持续播放的秒数（建议 5~30 秒）
数据备份与恢复
一键导出全部配置（房台、分区、管家、报警设置、历史记录）为 JSON 文件，可随时导入恢复，防止数据丢失。
Microsoft Access 数据库（把数据长期存成数据库）
点「导出 Access 数据表」会导出 8 张 CSV 数据表和一个 生成Access数据库.vbs，全部存到上面设置的数据库目录（和数据文件同目录）。到电脑上双击那个 .vbs，就在同目录生成 倒计时数据库.accdb，8 张表一次灌好，双击即可用 Access 打开。
CSV 也能直接在 Access 里用「外部数据 → 文本文件」导入或链接，任何装了 Office 的电脑都能用；本机没装 Access 引擎时脚本会给出明确提示，不影响系统正常使用。
数据库目录 / 本地数据文件（不怕清缓存 / 浏览器坏）
软件会自动选择最好的保存方式：打包成 EXE 后，若程序开放了原生文件能力，则打开即自动读取、每次保存自动写入，不需要任何授权弹窗、不用点任何按钮；若没有原生能力，则回退到「指定目录写入」方式（此时受浏览器安全机制限制，每次打开需确认一次授权）。
下方「EXE 原生写入」一行会显示当前检测结果与数据文件位置。此外随时可用上方「一键导出」备份为 JSON 文件。
想把数据放到 D 盘 / E 盘：先在资源管理器里建好文件夹（例如 E:\mzdata），把路径填进下面输入框，点「应用位置」即可；这里同时也是数据库目录——「导出 Access 数据表」导出的 CSV 与建库脚本、以及各种导出文件都会存到这里。若该位置不可写（打包程序未放开该磁盘的权限），会显示具体原因并自动回退到程序数据目录，数据不会丢。
